Security Audit & Lab Notes

Vulnerability Remediation Standard (OWASP & Defensive Rules)

[VULN-01] Path Traversal Defense PASSED / MITIGATED

Konteks: Pencegahan manipulasi traversal direktori parameter file (`../../etc/passwd`).
Remediasi: Normalisasi path ketat via `path.resolve()`, validasi allowlist direktori aman, dan penolakan traversal token sebelum akses storage.

[VULN-02] Broken Access Control PASSED / MITIGATED

Konteks: Perlindungan endpoint admin agar tidak dapat diakses akun publik tanpa otorisasi token session terverifikasi.
Remediasi: Verifikasi role-based access control (RBAC) di middleware sebelum routing dieksekusi dan isolasi session token.

[NET-03] Infrastructure Hardening (TKJ Lab) ACTIVE / HARDENED

Konteks: Konfigurasi router MikroTik & pembagian VLAN di lab jaringan.
Remediasi: Penonaktifan layanan rentan (WPS, UPnP, Telnet), isolasi segmen server dari host tamu, dan implementasi drop firewall rules pada paket tak dikenal.
